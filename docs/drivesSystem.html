09 · 技术债

技术债清单：高 / 中 / 低

分级口径：高 = 存在直接滥用路径或随库泄漏；中 = 平台绑定或仓库卫生； 低 = 可读性与死代码。全部条目带文件:行号落点。

高
SQL 注入面 —— 18 处 str.format 直拼 SQL（MyDataBase/__init__.py），UI 文本直达语句： 前缀查询 LIKE '%{}-%'（:210-213 ← mainwindow.py:636）、时间段查询（:215-218 ← :675）、 登录名与口令同理进 users 语句。
高
凭据随库入库 —— root/****（已脱敏）@127.0.0.1:3306 硬编码 （MyDataBase/__init__.py:11-17）；样例数据 4 用户共享 md5("hr") 哈希 adab7b70…784e （drives_management.sql:110-113，已本地复算验证）。
高
MD5 无盐口令哈希 —— calculate_md5 直出十六进制摘要 （mainwindow.py:66-70），彩虹表可逆；无锁定、无盐、无迭代。
中
Windows 平台绑死 —— win32api / win32print 为模块顶层导入 （mainwindow.py:19-20），非 Windows 环境 import 阶段即 ImportError，打印外的功能连带不可用。
中
生成代码与设计稿双份入库 —— store.py 79,248 B（占 Python 字节 59%）由 store.ui（65,512 B）生成；temp.ui（39,665 B）零引用。三份同源产物并存，改界面必须走 .ui 再生成。
中
调试输出遍地 —— 63 处 print（mainwindow.py 47 + MyDataBase 16）， 另有模块级 print(curlmd5('hr'))（storeUi/__init__.py:8）随每次 import 执行。
低
拼写进表结构 —— drives.etpye（etype 错拼，drives_management.sql:44）、 driveinfo.tpye（:27）、变量 statu（mainwindow.py:424）；改名成本已传导到 schema。
低
死代码 —— QtSql / QFile / QVariant / QFontDatabase 导入未用 （mainwindow.py:8-12）；add_drives2ware 内 22 行注释块（MyDataBase/__init__.py:66-87）； demo.py 注释掉的 import tensorflow（:12）；唯一 TODO（mainwindow.py:155）。
低
旧式 DB API —— pymysql.connect 位置参数写法 （MyDataBase/__init__.py:16-18），新版 PyMySQL 已弃用；README 仅 2 行，无部署说明。
